## The line

> My Wi-Fi went down during a job interview, so I just stared at the camera and said 'this is what working from home really looks like.'

## How it works

`main.py` writes that single line to `/output/entry.txt` (134 characters, one line, well under the 200-character limit).

Run it with:

```sh
python3 main.py
```
